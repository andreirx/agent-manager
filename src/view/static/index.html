Relay Viewer
How to read this page
Middle column
The diff of the selected changed file (green added, red removed, line numbers old | new), or a whole file opened at a line. Every identifier is a link.
Left click an identifier
Jumps to its best location — a likely definition if the index saw one (a class/function/def… keyword before it), else the top-ranked file — and lists every location on the right (* marks likely definitions).
Right click an identifier
A menu of all its locations; pick one to open it there.
Right column
Pointers for the file in the middle: code to open, tests that use the same names, docs that mention them. Score = sum of the rarity of the identifiers the two files share; the names shown are the rarest shared ones. Hints, not facts — a shared rare name is a lexical match, never a resolved reference.
Changed files, in affinity order
The candidate (working tree vs HEAD). Each file is placed after the earlier file it shares the most rare identifiers with, so related edits sit together.
Agent activity
What the newest relay run read, edited, ran and searched (live while it runs); below it, the code neighbors of the candidate the run never opened.
Bridges
Pick two directories: the identifiers both contain, rarest first — the names that cross a module or language boundary. Click a name for its locations.
Breadcrumb (header)
Your hops; click one to go back to it.
